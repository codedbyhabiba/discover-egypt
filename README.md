# Discover Egypt 🇪🇬

An elegant, responsive tourism showcase exploring the rich history, ancient wonders, and breathtaking natural landscapes of Egypt.

## 🌟 Overview

**Discover Egypt** is a multi-page web application highlighting 12 premier tourist destinations across Egypt:

- **Cairo** — The vibrant capital blending Islamic heritage, medieval architecture, and modern city life.
- **Giza** — Home of the Great Pyramids, the Sphinx, Saqqara, and the Grand Egyptian Museum.
- **Alexandria** — The Pearl of the Mediterranean, featuring the Corniche, Qaitbay Citadel, and Bibliotheca Alexandrina.
- **Luxor** — The world's greatest open-air museum, featuring Karnak, Valley of the Kings, and hot air balloon adventures.
- **Aswan** — Peaceful Nile vistas, Philae Island, Abu Simbel, and colorful Nubian culture.
- **South Sinai** — Sharm El Sheikh, Ras Mohammed, Dahab, Blue Hole, and Saint Catherine mountain trails.
- **Hurghada** — Premier Red Sea diving paradise, Giftun Island, coral reefs, and seaside promenades.
- **Marsa Alam** — Pristine diving sanctuaries, Sharm El Luli beach, and Wadi El Gemal National Reserve.
- **Siwa Oasis** — Natural salt lakes, therapeutic sand dunes, Shali fortress, and Cleopatra Spring.
- **Marsa Matrouh** — Mediterranean white sand coastlines, Agiba Beach, and Cleopatra's Bath.
- **Qena** — Upper Egypt traditions, Nile Corniche, and the grand Dendera Temple.
- **Suez** — Historic maritime gateway connecting global trade routes between East and West.

## 🛠️ Built With

- **HTML5** — Semantic, accessible markup with clean heading hierarchy.
- **Vanilla CSS3** — Responsive Flexbox layouts, custom typography, glassmorphism cards, and mobile-first media queries.
- **Optimized Media Assets** — High-resolution photography of Egyptian historical and natural landmarks.

---

## 📱 Responsiveness

The project is fully responsive and tested across all major viewport sizes:
- **Mobile** (375px – 480px)
- **Tablet** (768px – 1024px)
- **Desktop** (1200px+)

---

## 🚀 Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/codedbyhabiba/discover-egypt.git
   ```
2. Open `index.html` in your browser, or start a local HTTP server:
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your web browser.
